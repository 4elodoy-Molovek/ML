## Задание 1. Прогнозирование цены аренды Airbnb в Стамбуле

Ноутбук: [`01_Airbnb_Istanbul.ipynb`](01_Airbnb_Istanbul.ipynb)

Данные: [Inside Airbnb](https://insideairbnb.com/get-the-data/), Istanbul, снимок от 30.06.2026 — копия лежит в [`data/listings_istanbul.csv.gz`](data/listings_istanbul.csv.gz) (26 631 объявление, 90 столбцов).

Задача — регрессия: по характеристикам объявления (район и координаты, тип жилья, вместимость, удобства, правила бронирования, отзывы, сведения о хозяине, тексты описания) предсказать цену за ночь.

В ноутбуке: постановка задачи, разбиение на train/test, визуализация и описательные статистики, обработка выбросов и пропусков, кодирование категориальных признаков, нормализация, метод k ближайших соседей с подбором k по кросс-валидации, сравнение с линейной регрессией, случайным лесом и градиентным бустингом, TF-IDF по текстам, исключение коррелированных признаков, выводы.

| Модель | RMSE (log цены), тест | R², тест |
|---|---|---|
| Градиентный бустинг | 0.443 | 0.85 |
| Случайный лес | 0.457 | 0.84 |
| Линейная регрессия (Ridge) | 0.543 | 0.77 |
| kNN, k = 7 (веса по расстоянию) | 0.549 | 0.77 |
| Константа (медиана) | 1.150 | 0 |
